# Held-out acceptance scenarios

These are IssuePilot's held-out acceptance scenarios. They were written on 2026-10-21 by Claude Code (model: sonnet) from the product intent and `contracts/backtest.md` only, without seeing the implementation, in the pack `a separate directory`.

- The implementing agent runs them and never edits them.
- A scenario that looks wrong is re-authored by its author, not fixed in place.
- They run with the command in `verify.json`.

`COVERAGE.md` maps each scenario to the acceptance IDs it covers and lists what the scenarios cannot test.
